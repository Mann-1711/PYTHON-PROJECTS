## 💻 How to Run

Make sure Python is installed on your computer.

Clone the repository:

```bash
git clone https://github.com/Mann-1711/PYTHON-PROJECTS.git
```

Move into the project folder:

```bash
cd PYTHON-PROJECTS
```

Run any Python file:

```bash
python filename.py
```

For example:

```bash
python calculator.py
```

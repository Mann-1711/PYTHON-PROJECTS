# 💻 Running the Projects

Make sure Python is installed.

Clone the repository:

```bash
git clone https://github.com/Mann-1711/PYTHON-PROJECTS.git
```

Enter the repository:

```bash
cd PYTHON-PROJECTS
```

Run any project:

```bash
python filename.py
```

For example:

```bash
python unit_converter.py
```
